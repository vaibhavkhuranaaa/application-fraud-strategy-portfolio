# Decision 0005: Define monitoring and exit

Date: 2026-08-18

## Decision

Use one seven-domain control map for calibration, population stability, investigator yield, capacity,
customer friction, label maturity, and segment performance. Give every control an accountable role,
cadence, threshold basis, trigger, response, evidence source, and limitation. Distinguish evidence that is
measurable now from controls that need production data.

## Why

A refusal without monitoring and exit criteria is only a report. A risk owner needs to know what is
controlled, who responds, what evidence is missing, and what would justify reopening the decision.

## Alternatives rejected

- Mark unavailable controls as passing. Missing production evidence is not a zero or a pass.
- Invent investigator, customer, or label-maturity baselines. BAF contains none of them.
- Assign named individuals. The project can design accountable roles but cannot claim organizational
  acceptance.

## Not done

No production feed, operating owner, realized loss, staffing level, or customer outcome is claimed. No
control changes the recorded refusal or promotion contract.

## Changed

The governance record now defines seven role-assigned controls and four explicit conditions required before the
decision can be reopened.
